    Browse lists only samples that pass these filters and the download and unpack limits. The Show menus on the Fetch tab then narrow that list.
    
 
    

    

    
 
    Analysis
    
  
    Time per sample
    Past it the analysis is stopped
    s, 10 – 300
    
  
    Extra time for capa
    s, 30 – 600
    
  
    Samples at once
    Auto = one per VM CPU, as far as free RAM allows. More than the VM's CPUs is allowed but not faster: they share the CPUs and get more time each.
    
  
    capa on packed programs
    Packed = capa only sees the unpacker
    
 
    
 
    Files over the unpack limit 🔒 safety limit
    
  
    Unpack limit
    Zip-bomb guard (SPEC). Can go lower, never off
    
  
    When a sample is bigger
    The file itself is never kept
    
  
    "Keep its info only" adds a library row with hash, family, type and tags, marked too big · not analysed.
